# PickAPig
Pigs are one of my favorite animals and one of the most popular choices of livestock (when being popular is not a good thing!) Pigs are intelligent, emotional, and adorable creatures and I know I am not the only one who feels this way!
With PickAPig, I am giving animal lovers like myself a platform for which they can learn about pigs, but most importantly save them from a cruel slaughter. 
My goal is to use an API to connect these users to real organizations that protect and save pigs and can place them with their very own pig! https://www.pigplacementnetwork.org/ is a great site for this. 

## 🌟 Key Features

* **Facts and Q&A:** Dive into all things pigs with scrollable forms with common questions and respective answers.
* **API usage:** Look at real live pigs that could potentially be yours through an API request from real sanctuary sites.
